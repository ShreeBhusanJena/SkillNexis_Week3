# SkillNexis Week 3: Python & Data Wrangling

## Project Overview

This project demonstrates data cleaning, data manipulation, filtering, and visualization using Python.

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Project Tasks

1. Loaded the original dataset using Pandas.
2. Removed duplicate rows.
3. Handled missing values in the Date and Calories columns.
4. Created a new `Calories_Status` column to classify calorie values as High or Low.
5. Filtered workouts lasting 60 minutes or longer.
6. Created visualizations using Matplotlib and Seaborn.

## Project Files

* `data.csv` — Original dataset.
* `cleaned_data.csv` — Cleaned dataset.
* `long_workouts.csv` — Filtered workout data.
* `duration_distribution.png` — Workout duration distribution.
* `duration_vs_calories.png` — Workout duration versus calories burned.
* `average_calories.png` — Average calories burned by workout duration.
* `main.py` — Python source code.

## How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

Run the project:

```bash
python main.py
```
